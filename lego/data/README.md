Hier liegen die Rebrickable-Daten (`parts`, `colors`, `part_categories`,
`part_relationships` als `.csv.gz`) plus `version.json`.

Sie werden von der GitHub Action `.github/workflows/lego-data.yml` geschrieben
(oder lokal mit `bash lego/tools/update-data.sh`). Nicht von Hand bearbeiten.
Quelle: https://rebrickable.com/downloads/
